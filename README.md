# 🏊 Piscinas inc. - Demo Landing Page

Este projeto é uma Landing Page de demonstração de alta conversão para uma empresa fictícia de construção de piscinas de alto padrão, "Piscinas inc.".

O objetivo é apresentar um design premium, responsivo e persuasivo para clientes B2C (residencial) e B2B (corporativo).

## 🚀 Tecnologias

- **HTML5**: Estrutura semântica e SEO friendly.
- **CSS3**: Estilização moderna com variáveis (:root), Flexbox, Grid e animações.
- **JavaScript (Vanilla)**: Interações leves, scroll reveal e menu sticky.
- **Assets**: Imagens otimizadas e organizadas.

## 📂 Estrutura do Projeto

```
/
├── index.html          # Arquivo principal
├── assets/
│   ├── css/
│   │   └── style.css   # Estilos globais
│   ├── js/
│   │   └── script.js   # Lógica de interação
│   └── img/            # Imagens do projeto
└── README.md           # Documentação
```

## 🛠️ Como Executar

1.  Clone este repositório ou baixe os arquivos.
2.  Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Edge, Firefox).
3.  Nenhuma instalação de dependência ou servidor é necessária.

## ✨ Funcionalidades

- **Hero com Parallax**: Impacto visual imediato.
- **Menu Sticky**: Navegação fixa ao rolar a página.
- **Scroll Reveal**: Animações de entrada suaves nos elementos.
- **Galeria Interativa**: Imagens com legendas visíveis.
- **Design Responsivo**: Adaptado para Desktop, Tablet e Mobile.
- **Botões CTA**: Foco em conversão para WhatsApp.

## 🎨 Design System

- **Cores**: Azul Profundo (#004E64), Dourado (#D4AF37) e Branco.
- **Tipografia**: 'Playfair Display' (Títulos) e 'Outfit' (Corpo).
